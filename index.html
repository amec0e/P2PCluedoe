🕵️ P2P Cluedoe 🔍

Local WiFi Game Night - Internet Required for PeerJS

⚠️ Known Quirks
  • Don't Background the Tab/App: If you background the tab on desktop or switch apps on mobile/tablets, there's a chance you will lose connection. Keep the game visible while playing.
  • Disable Screen Auto-Lock: On mobile/tablet devices, ensure your screen is set to not auto-lock. When the screen locks, your device may suspend the connection, which can disconnect you from the game.
  • Timer Desync: If you background the app for a few seconds and come back, your timer will have paused and is no longer in sync with other players. However, as long as the host's timer remains correct (host doesn't background), the game will continue as normal since only the host enforces turn time limits.
🎮 How to Play

Players: 2-6 players required

Setup:

  1. One player hosts the game and shares the 8-digit code
  2. Other players join using the code
  3. All players select their character
  4. Host starts the game when ready (2-6 players)

Your Turn:

  1. Select a Destination: Choose which room you want to travel to
  2. Roll Dice: Keep rolling (two dice, 2-12 range) to accumulate moves until you reach your destination
  3. Arrive at Room: Once you have enough moves, you'll arrive automatically
  4. Make a Suggestion (Optional): Suggest a suspect, weapon, and the room you're in. Other players will try to disprove it
  5. Make an Accusation (Optional): If you're confident, make a final accusation. Wrong = elimination!
  6. End Turn: Pass to the next player

If Eliminated: You can no longer make moves, suggestions, or accusations. However, you can still show cards to disprove other players' suggestions.

Detective Notes: Click cards to mark them as eliminated (✗) or likely (⭐) to help track your investigation

Winning: Correctly accuse the right suspect, weapon, and room!

🏠 Local Game Night Setup

Host this on your local network (e.g., Raspberry Pi on your home WiFi). Only people connected to your WiFi can access and play the game. Player devices must be able to communicate with the host server (Raspberry Pi).

PeerJS is used for real-time communication between players, but requires internet to function. Game data is sent peer-to-peer through PeerJS servers.
